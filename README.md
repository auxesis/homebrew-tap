# auxesis/homebrew-tap

Homebrew formulae for [auxesis](https://github.com/auxesis) projects.

```sh
brew install auxesis/tap/<formula>
```

| Formula | Description |
|---|---|
| [tally-light](https://github.com/auxesis/tally-light) | Turns a Philips Hue lamp red while your webcam is in use |

Formulae are generated and pushed by each project's release workflow. Don't edit them by hand: the next release overwrites them.
